# Protótipo de painel COPI

Protótipo front-end responsivo para estudo e adaptação.

## Como abrir
1. Extraia a pasta do ZIP.
2. Abra `index.html` no navegador. Para trabalhar no VS Code, você pode abrir a pasta e usar a extensão Live Server.
3. O gráfico usa Chart.js por CDN, então precisa de internet para carregar essa biblioteca.

## Arquivos
- `index.html`: estrutura das páginas e componentes.
- `script.js`: navegação lateral, filtros demonstrativos, tabelas, exportação CSV e gráfico.
